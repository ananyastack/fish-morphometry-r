# Fish Morphometric Analysis using R

This repository contains my undergraduate Zoology dissertation on the comparative morphometric analysis of *Labeo rohita* and *Catla catla* from West Bengal, India.

## Project Overview

This project investigates morphological and physiological variation between two commercially important freshwater fish species using statistical analysis in R.

## Methods

- Principal Component Analysis (PCA)
- ANOVA
- Tukey HSD
- Linear Regression
- Shapiro-Wilk Normality Test
