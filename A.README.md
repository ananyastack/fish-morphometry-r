# Fish Morphometric Analysis using R

This repository contains my graduation thesis on the comparative morphometric analysis and GIS assisted provenance mapping of two economically major carps *Labeo rohita* and *Catla catla* of West Bengal, India.

## Project Overview

This project investigates morphological and physiological variation between two commercially important freshwater fish species using statistical analysis in R.

## Methods

- Principal Component Analysis (PCA)
- ANOVA
- Tukey HSD
- Linear Regression
- Shapiro-Wilk Normality Test
